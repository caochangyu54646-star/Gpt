# 夏季私人相册抓拍

## 任务与默认值

用户调用本技能生成图片时，使用可用的图像生成工具执行，不仅提供提示词。用户仅要求编辑技能或提示词时，不生成图片。

目标是私人相册感、夏季旅行感、熟悉的同行者视角、自然抓拍感与真实摄影感。画面应像朋友、伴侣或同行者突然举起相机记录夏日生活，而非商业泳装广告或摆拍宣传照。

没有指定人物时，默认一位原创成年女性；没有指定角色时，不自动加入 COS；没有参考图时，直接创建原创人物。自行选择合理的场景、泳装、动作和摄影媒介，不为可推断的偏好反复询问。

## 不可省略的约束

- 每次调用只生成一张独立照片：ONE IMAGE / ONE FRAME / ONE SCENE / ONE CONTINUOUS MOMENT。
- 单图允许多人，但所有人必须在同一空间、同一时间、同一连续事件中。
- 所有泳装主要人物明确为 21–30 岁成年人，具有清晰成年外貌与比例。年龄较小、不明确或幼态的角色必须转译为明确成年的 COS reinterpretation。
- 禁止拼图、联系表、九宫格、多窗口、多联画、分镜、照片墙、底片排列及照片中嵌套其他照片。
- 默认无文字、标识、日期、时间、编号、水印、取景框或相机界面。胶片、CCD 和 DV 仅表示成像质感。
- 保持自然人体比例、重力、关节与正确手部结构；禁止重复人物、重复肢体、身体融合和极端不现实腰臀比。

## 参考图与身份

先判断每张参考图负责的内容：身份、脸型、发型、妆容、服装、配件、姿势、构图、机位、光线、色彩、场景或摄影风格。只约束对应内容，不无条件复制整张参考图。

身份参考保留脸型、五官结构、眼鼻嘴形、下颌、发际线和面部比例；允许表情、湿发、光照、晒红、妆容及水珠随新场景自然变化。原则：Same identity, new candid moment。

多人物参考分别建立独立 Identity Anchor，不融合五官、不交换人脸。人物参考加 COS 时，脸由人物参考决定，角色视觉由角色要求决定。

构图参考仅提取距离、高度、主体位置、透视、前中后景、人物面积和身体方向。姿势参考提取重心、肩胯、手脚趋势、旋转、头部与视线，再转译为进行中的自然动作。风格参考仅提取曝光、反差、颗粒、动态范围、色温、高光、阴影、闪光、柔焦、光晕和构图松散程度。

使用图像工具支持的参考图机制。若必要参考图无法访问，要求重新提供；不得宣称已经保留未见过的人物身份。

## 通用角色 COS

支持动漫、漫画、游戏、电影、电视剧、小说、特摄、虚拟角色、原创 IP 与用户 OC；支持同作品组合及跨作品联动。

解析角色的重要视觉 DNA：发色、发型、刘海、瞳色、发饰、头饰、妆容、主辅色、结构、饰品、符号、图案、纹身和适用道具。角色信息无法可靠确定且影响辨识时，简短询问作品或要求参考图，不臆造关键特征。

COS 强度：

- Inspired：轻度继承配色、发型与气质。
- Recognizable Real-Life COS：默认；保留关键发型、配件、符号、颜色与人格，呈现真实成年高质量 COSER。
- Full COS：强化原作造型、妆容、头饰、服装结构与道具，同时适应夏季真实环境。

将角色主辅色、剪裁、几何、图形、材质、配饰与符号转译成真实可穿的泳装，不机械地把完整战斗服搬进泳池，也不只给普通泳装换色。

多人分别建立 Character Anchor 与 Identity Anchor。每人的发型、配色、服装、饰品与人格保持独立，禁止属性串位。泳装采用不同轮廓、领口、肩带、剪裁与符号，同时协调整体视觉。

默认现实中的 COSER 夏季旅行；仅在用户明确要求时进入原作世界场景。即使科幻、奇幻或赛博朋克环境，也保持一张连续瞬间的照片。

人物行为继承角色人格：克制安静、元气泼水、松弛戏谑、挡镜头假装生气等，避免所有角色成为同一类人物。

## 场景、动作与关系

选择一个真实地点，例如庭院或酒店泳池、海边民宿、浅海、岩石海湾、木码头、湖边、森林溪流或户外冲洗区。

只选择一个核心事件，动作正在发生：泼水、躲水、回头等同行者、递饮料、挡镜头、牵手下水、抢浴巾、整理湿发等。使用 mid-action、unfinished gesture、caught between movements，不采用标准模特姿势。

多人动作围绕同一事件形成反应链，例如 A 泼水、B 躲水、C 发笑；不要堆叠互不相关的活动。构图不对称，允许前后距离、局部遮挡与自然失焦，避免横排、等距、全员正面或同时看镜头。

使用 Boyfriend / Partner / Friend / Companion POV，表达熟悉摄影者的自然反应。摄影者的手、前臂或腿部边缘可少量出现作为视角证据，不能抢走主体。

加入少量生活痕迹，如湿拖鞋、用过的毛巾、冰饮、草帽、帆布袋、防晒霜、泳镜或被踩乱的沙，不堆满场景。

## 真实身体与水

皮肤保留毛孔、细汗毛、轻微肤色不均、唇纹、眼下纹理、自然泛红、皮脂光泽、水珠和晒痕；可有微弱雀斑、淡痘印或眼袋。禁止塑料、蜡质、CGI 皮肤和过度磨皮。

湿发状态由行为决定：全湿、半湿、贴脸贴肩、发梢滴水或擦拭后半干，符合物理逻辑。布料有真实材质与贴合，湿处颜色自然变深，人体肌肉张力和皮肤折叠合理。

至少包含一种水元素：水面、海浪、水花、镜头水珠、湿发、湿润皮肤、滴水、湿地面、波纹、反射或淋浴。

COS 呈现真人皮肤、真实假发纤维、妆容、泳装材质与环境光，不使用游戏模型脸或动漫脸贴真人身体。

## 摄影语言

每张只选一种主要媒介：

- 35mm Film：自然颗粒、轻微高光光晕、柔和高光过渡与少量失焦。
- 90s Compact Film：消费级镜头、柔软边角、不完美自动对焦与随意构图。
- 2000s CCD：小传感器质感、CCD 噪点、有限动态范围、冷高光，可用直闪。
- Disposable Camera：固定焦点感、颗粒、硬闪与轻微偏色。
- Early Smartphone：随手裁切、少量运动模糊与不完美 HDR。

优先 28–40mm，必要时采用 24mm 或 50mm，少量使用 70mm。机位可在水面、池边、腰部、胸口、眼平、坐姿或躺椅高度，避免标准商业摄影视角。

自然光优先侧逆光、轮廓光、水面反射光；可采用上午、午后、树荫、黄金时刻或阴天光线。

少量摄影不完美可包括非中心构图、自然裁切、前景遮挡、轻微地平线倾斜、运动模糊、对焦慢半拍、局部过曝、耀斑和边角柔化。摄影失误不能变成生成错误。

## 执行流程

1. 提取人物数量、身份、角色、参考图职责和用户指定场景；缺省采用合理默认值。
2. 明确每位相关人物为 21–30 岁成年人，建立独立身份与角色约束。
3. 为每人选真实可穿的独立泳装，选择一个地点与一个进行中的事件。
4. 指定熟悉的同行者 POV、一种媒介、焦段、距离、机位、构图、水元素、自然光与真实皮肤。
5. 写成描述单幅照片的完整提示词，附必要否定约束；不要将选项清单直接交给生成器造成多场景拼接。
6. 调用图像生成工具，只请求一张图片。遵循工具的参考图、透明背景与结果展示约定。
7. 能检查结果时，检查成年外貌、单图连续场景、身份独立、核心事件、正确解剖与摄影真实性。不声称完成未实际执行的检查。

## Negative guidance

no collage, no contact sheet, no photo grid, no multiple images inside one canvas, no split screen, no multi-panel layout, no storyboard, no diptych, no triptych, no film strip, no Polaroid collage, no moodboard, no character sheet, no character lineup, no magazine layout, no commercial swimwear advertising, no studio posing, no fashion lineup, no stiff front-facing group pose, no plastic skin, no CGI skin, no excessive beauty filter, no identity mixing, no character attribute leakage, no duplicated people, no duplicated limbs, no malformed hands, no warped anatomy, no text, no watermark, no viewfinder UI.

## 最终检查

人物明确成年；身份与角色独立；泳装真实可穿；所有人物处于同一场景与同一连续瞬间；只有一个正在发生的核心事件；自然互动；一种主要摄影媒介；合理机位、皮肤与人体；含水元素；无商业摆拍；无文字界面；无任何拼图或多画面。

最终感受应是：“他们本来就在一起过夏天，而摄影者恰好按下了快门。”
